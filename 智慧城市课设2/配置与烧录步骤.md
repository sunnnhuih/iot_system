# CC2530 智慧城市课设配置与烧录步骤

## 1. 两块板子的角色

| 物理板 | 角色 | 烧录工程 | 外接模块 |
| --- | --- | --- | --- |
| 小板：普通 CC2530 节点 | 环境采集终端 | `firmware_terminal/Project/rf_set.ewp` | DHT11、MQ-2、光敏、人体红外、继电器、蜂鸣器 |
| 大板：CC2530 + ESP8266 Wi-Fi 网关 | ZigBee-Wi-Fi 网关 | `firmware_gateway/Project/rf_set.ewp` | 不接传感器；ESP8266 负责连接手机热点 |

两板无线参数已固定为 PAN ID `0x1234`、信道 `11`；小板地址 `0x1000`，大板地址 `0x2000`。不要只烧一块板，否则不会有数据。

## 2. 小板接线

断电后接线。小板上的黄色 GPIO 排针请按丝印找对应的 `P0.x` / `P1.x` 引脚；所有模块 GND 必须与小板 GND 共地。

| 模块 | 模块引脚 | 小板连接位置 | 供电 | 程序含义 |
| --- | --- | --- | --- |
| DHT11 | DATA | GPIO 排针 `P0.0` | `3.3V` | 温度、湿度 |
| 人体红外 HC-SR501 | OUT | `PEOPLE` 插座的信号脚 / `P0.4` | 使用 PEOPLE 插座的 `5V` 和 GND | 高电平表示有人 |
| 继电器 | IN | `RELAY` 插座信号脚 / `P0.5` | 使用 RELAY 插座电源和 GND | 高电平吸合，模拟路灯 |
| 有源蜂鸣器 | SIG | `BUZZER` 插座信号脚 / `P0.7` | 使用 BUZZER 插座电源和 GND | 低电平鸣叫 |
| MQ-2 | DO | `MQ2/LIGHT` 插座 DO / `P1.5` | 按插座丝印接 `5V`、GND | 低电平表示检测到烟雾 |
| 光敏模块 | DO | GPIO 排针 `P1.4` | 优先 `3.3V`、GND | 低电平表示环境暗 |

### 光敏模块的特别说明

板载 `MQ2/LIGHT` 插座的 DO 固定连到 `P1.5`，因此只能插 MQ-2 或光敏模块中的一个。为了同时保留两种检测，本工程把光敏 DO 改到空闲 GPIO `P1.4`，必须用三根杜邦线单独接：`VCC -> 3.3V`、`GND -> GND`、`DO -> P1.4`。

不要将一个由 `5V` 供电且 DO 输出为 `5V` 的通用光敏模块直接接入 P1.4；优先用 `3.3V` 供电，或确认 DO 已经过 3.3V 电平转换。MQ-2 请使用开发板专用 `MQ2/LIGHT` 插座，不要把原始 5V DO 线直接跳接至 GPIO。

## 3. 小板烧录

1. 将 CC Debugger 或 SmartRF04EB 的 10 针调试线接到小板 `DEBUG` 接口，再给小板 USB 供电。
2. 打开 IAR Embedded Workbench，选择 `File -> Open -> Workspace`，打开 `firmware_terminal/Project/rf_set.eww`；也可直接打开 `rf_set.ewp`。
3. 在左上角选择 `Debug` 配置，执行 `Project -> Make`，确认编译没有 Error。
4. 执行 `Project -> Download and Debug` 下载；完成后停止调试并复位小板。
5. 小板 LCD 首行出现 `Smart City Terminal` 即表示终端程序已启动。

## 4. 大板烧录与 Wi-Fi 配置

### 4.1 烧录大板的 CC2530

1. 调试器接大板左侧 ZigBee/CC2530 的 `DEBUG` 接口；ESP8266 不需要单独烧录。
2. 在 IAR 打开 `firmware_gateway/Project/rf_set.eww`，选择 `Debug`，执行 `Project -> Make`。
3. 执行 `Project -> Download and Debug`，下载后复位大板。
4. 大板 LCD 首行出现 `Smart City Gateway` 即表示网关 CC2530 程序已启动。

### 4.2 设置 ESP8266 连接手机热点

1. 手机开启热点，建议名称和密码只用英文、数字；不要开启“禁止设备互访”或客户端隔离。
2. 电脑先连接该热点，按 `Win + R`，输入 `cmd`，执行 `ipconfig`。记录“无线局域网适配器 WLAN”下的 IPv4 地址和默认网关，例如 `192.168.43.101` / `192.168.43.1`。
3. 选择一个同网段且没被使用的网关固定 IP，例如上例填写 `192.168.43.150`；如果电脑看到的是 `172.20.10.x`，则网关也填写 `172.20.10.150`。前三段必须和电脑 IPv4 地址一致。
4. 大板红色 6 位拨码开关中，只将 `3`、`4` 拨到印有 `ON` 的一侧；`1`、`2`、`5`、`6` 均拨到另一侧。这是 **Wi-Fi 串口 -> USB** 配置位置。USB 连接电脑。
5. 双击 `D:\桌面\物联网\project2\工具\ESP8266配置工具.exe`，选择新出现的 COM 口，点击“1、搜索模块”，再点击“2、查询参数”。
6. 在配置工具填写：无线模式 `STA`；网络名称为手机热点名称；密码为热点密码；网络协议选择 `TCP 服务器`；本地端口填写 `8080`；本地 IP 填上一步选定的固定 IP。点击“3、设置参数”。
7. 等待约 10 秒，在电脑命令提示符执行 `ping 192.168.43.150`（替换为自己填写的 IP）。有“来自 ... 的回复”才表示 ESP8266 已连上热点。
8. 大板断电后，只将 `5`、`6` 拨到 `ON` 一侧；`1` 到 `4` 均拨到另一侧。这是 **ZigBee 串口 <-> Wi-Fi 串口** 透传位置。再重新上电。

`1`、`2` 到 ON 是 ZigBee 串口 -> USB 的普通节点调试位置，本项目正常运行时不要使用它。

运行时，拨码不能停留在 Wi-Fi -> USB 配置位置，否则大板的 CC2530 无法和 ESP8266 通信。

## 5. 电脑与手机网页

1. 电脑也连接同一手机热点。
2. 进入 `python_server`，将 `.env.example` 复制为 `.env`，填写：

```ini
DEEPSEEK_API_KEY=你的DeepSeek密钥
GATEWAY_HOST=大板ESP8266的IP
GATEWAY_PORT=8080
WEB_PORT=5000
```

3. 运行 `python -m pip install -r requirements.txt`，再运行 `python app.py`。
4. 电脑终端出现 Flask 启动信息后，使用 `ipconfig` 查找电脑连接手机热点的 IPv4 地址。
5. 手机浏览器打开 `http://电脑IPv4地址:5000`，例如 `http://192.168.43.101:5000`。
6. 网页显示“网关在线”后，遮挡光敏、走到人体红外前、触发 MQ-2，可依次验证数据；自动模式下夜间有人会开继电器，烟雾会响蜂鸣器并点亮警示 LED。

## 6. 建议的上电与排错顺序

1. 先给小板上电，确认 LCD 显示终端名称。
2. 再给大板上电，确认 LCD 显示网关名称，并让 ESP8266 连上热点。
3. 最后运行电脑 Python 服务，等待网页从“网关未连接”变成“网关在线”。
4. 先测自动检测，再切换手动模式测试网页按钮，最后测试 Agent，例如输入“切换手动模式后打开路灯”。

若网页一直“网关未连接”，先检查 `.env` 的网关 IP、端口 8080、拨码是否在 ZigBee <-> Wi-Fi 透传位置，以及电脑/大板是否真的连在同一手机热点。
